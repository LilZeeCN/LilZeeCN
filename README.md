<sub>02 / THE THREAD</sub>

### 让 AI 接入真实工具，也让 AI 学会如何教学。

一边是工具：打通协议、格式与模型的边界，让 Agent 真的能交付文件和结果。<br>
另一边是学习：把一次性的对话，变成能积累、能复习、能验证的长期过程。

这是这四个项目背后，同一个想继续探索的问题。
